Hotel check-in

Pocket sheet for Lesson 0021. Pattern: Khali room ideya? → stay length → Key kodri → check-out / bill.

Front-desk loop

  1. Namaskara. Nanna booking ide. Nanna hesaru …
  2. Ondu raatri beku. (or eradu raatri)
  3. Room eshtu? / Ondu raatri-ge eshtu?
  4. Key kodri. WiFi password heli.
  5. Check-out yaavaaga? / Check-out eshtu gante?
  6. Bill kodri. Dhanyavadagalu.
