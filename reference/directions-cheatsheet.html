↑ straight eduru

Ask / confirm

  1. … elli ide? — where is …?
  2. Heghe hogbeku? — which way?
  3. Eduru hogi — go straight
  4. Balakke thirgi — turn right
  5. Yedakke thirgi — turn left
  6. Swalpa eduru, nantara balakke — a bit straight, then right
  7. Hattira / dooradalli — near / far
  8. Idhe na? / Alli na? — this way? / there?
  9. Gothaytu / Gottila — got it / don’t know
