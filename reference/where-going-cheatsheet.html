Reference Spoken Kannada

Where are you going?

Pocket sheet for Lesson 0002. Pattern: place + -ge + hogtidini / hogtiddiri.

Core loop

  1. Elli hogtiddiri? — where are you going? (polite)
  2. Naanu manege hogtidini — I’m going home
  3. Office-ge hogtidini — I’m going to the office
  4. Kelasa-ge hogtidini — I’m going to work
  5. Sari, nodona — okay, see you
  6. Olle dinagalu — have a good day
  7. Hogtini, sari — I’ll get going, okay
